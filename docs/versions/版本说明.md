# iAMAS 版本说明

本仓库保留原始源码与服务器最新测试版本，便于对照。

| 分支 / 标签 | 内容 |
|---|---|
| `baseline` / `v2.6.5-original-baseline` | 原始 `iamas-v2.6.5.zip` 的源码，未加入 SW64 兼容或优化修改 |
| `main` / `sw64-12h-9737442` | 最近完成 12 小时模拟的 SW64 有效源码组合，包含 precomm、vertmx Kokkos 和细分计时 |

两个版本按先后顺序提交，可使用 GitHub Compare 或 `git diff baseline..main -- src` 查看变化。

## 基线来源

原始归档：`iamas/baseline/iamas-v2.6.5.zip`。

SHA-256：`8ac84f46a672f2e28664072964d832b721bd2ff30e22880bdf4cdef77424c07e`。

解压后源文件逐项记录于 [baseline-source-manifest.json](baseline-source-manifest.json)，并保留 Unix 符号链接和可执行权限。源码根目录的 README、LICENSE 和其他原始文件保留原文。

这里的 baseline 是原始发布源码；之前 12 小时性能表中的“优化前”是已经做过 SW64 适配的运行版本，不能将原始源码直接当成那次计时所用的可执行文件。
